# Sleepy v2

Flutter prototype for a sleep app.

Included:
- Sleepy dark UI
- Rain, Ocean, Forest and White Noise sound choices (UI prototype)
- 15/30/60 minute sleep timer
- Play/pause session UI
- Premium screen showing ₹49/month
- Premium demo toggle

Important:
- The sound choices are currently UI-only; add properly licensed audio files and an
audio playback package for real sounds.
- The Premium button is a demo only. Before charging users, connect an approved
in-app purchase/subscription system and show the required store disclosures.
- Add real local notifications for bedtime reminders before production release.

Run:
flutter pub get
flutter run
